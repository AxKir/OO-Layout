# Layout Panel

Layout Panel is a plugin for OnlyOffice Presentation Editor that gives quick access to the most common layout controls for selected objects.

It is designed for slide work where you frequently need to adjust:

- width and height
- x/y position
- rotation
- alignment to selection
- distribution across multiple objects
- aspect-ratio locking while resizing

## Features

- Adjust size, position, and rotation for selected objects
- Align objects to the left, center, right, top, middle, and bottom
- Distribute objects horizontally or vertically
- Lock aspect ratio while resizing
- Works directly inside the OnlyOffice presentation editor panel

## Supported editor

- Slides / Presentation Editor

## Files

- `config.json` — plugin metadata and marketplace configuration
- `index.html` — plugin UI
- `css/layout.css` — styling for the pane and controls
- `scripts/layout.js` — plugin logic and editor interactions
- `resources/` — icons, screenshots, and store assets

## Local testing

Open the plugin in OnlyOffice Presentation Editor and select one or more objects to test the controls.

## Notes

This plugin is intended to reduce the need to hunt through editor menus for common object layout tasks.
